# Dino Math App 🦕

A playful dinosaur math safari for ages 4-8, covering 1st-3rd grade math.

**8 Worlds:** Counting Valley, Addition Volcano, Subtraction Swamp, Pattern Jungle, Measure Mountain, Shape Canyon, Multiplication Plains, Reasoning Reef

**Features:**
- Read-aloud questions & answers
- Dino hands/horns/claws instead of leaves
- Unique dino roar per world on correct answers
- Numbers < 100 (Easy 0-20, Medium 0-50, Hard 0-99)
- Funny dino stories with voiceover
- Endless examples, animations, sounds, stars & badges

Built with Hatch. Live at: https://agent.meta.ai/s/dino-math-app-wxn5xrxf2xldxxxlxi

## Run locally
Just open `index.html` in a browser. No build needed.

## Deploy
Host `index.html` anywhere static (GitHub Pages, Netlify, Vercel).
